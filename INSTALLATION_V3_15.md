# Mise à jour V3.15 — Navigation et Mes droits

Cette archive contient exclusivement : `app.js`, `styles.css`, `index.html` et `sw.js`.

## Changements

1. Dans **Mes outils → Mes droits**, le message « Les fiches sont informatives… » est déplacé **après** le bouton « Contacter le SNUDI FO ».
2. Dans la barre de navigation rouge inférieure, un sixième bouton **Contact** (pictogramme téléphone) est ajouté **entre Outils et Menu**. Il ouvre l'écran de contact.
3. Les six boutons s'adaptent aux petits écrans (320 px et plus).

## Installation sur GitHub Pages

1. Conserver une copie du dépôt et des fichiers existants.
2. À la racine du dépôt `adrienheritier/snudifo30`, remplacer les quatre fichiers présents dans cette archive.
3. Valider sur la branche `main` et laisser GitHub Pages se déployer.
4. Fermer puis rouvrir l'application installée ou actualiser pour renouveler le cache du service worker. Si l'ancienne interface persiste, forcer un rechargement.

**Aucun fichier du dossier `content`, aucun PDF, aucune image et aucun fichier administrateur n'est modifié.**
