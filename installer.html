Ouvrir SNUDI-FO 30

Si le bouton « Installer » n'apparaît pas :

  1. Ouvrez ce lien dans Chrome ou Samsung Internet.
  2. Ouvrez le menu du navigateur ⋮ (ou ☰).
  3. Choisissez Installer l'application ou Ajouter à l'écran d'accueil, puis confirmez.

Si le QR code s'ouvre dans un navigateur intégré (WhatsApp, Facebook…), choisissez d'abord « Ouvrir dans le navigateur ».

Sur iPhone ou iPad : l'installation se fait avec le menu de partage.

  1. Touchez Ouvrir SNUDI-FO 30 ci-dessus pour accéder à l'application.
  2. Dans votre navigateur, touchez Partager □↑ (en bas ou en haut selon le navigateur).
  3. Choisissez Sur l'écran d'accueil.
  4. Si proposé, laissez activé Ouvrir comme app, puis touchez Ajouter.

Si vous ne voyez pas cette option, ouvrez l'application dans Safari et recommencez. Aucun bouton web ne peut installer directement une app sur iPhone.

Sur ordinateur, scannez le QR code ci-dessous avec l'appareil photo de votre téléphone.

Vous pouvez aussi ouvrir l'application sur cet ordinateur ou utiliser l'option d'installation de votre navigateur si elle est proposée.
